# Fun Arcade

A playful mini-game hub with several games in one place.

## Included games
- Memory Match
- Tic-Tac-Toe
- Reaction Rush
- Number Guess

## Run it locally
Open `index.html` in your browser, or from a terminal run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes
This is a lightweight static app, so there are no dependencies to install.
